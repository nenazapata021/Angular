# Introducción a TypeScript

Proyecto de aprendizaje sobre los fundamentos de TypeScript, creado por **Edna Castañeda Zapata**.

## Descripción

Este proyecto es una guía práctica que cubre los conceptos esenciales de TypeScript, desde tipos básicos hasta funcionalidades avanzadas como decoradores y genéricos.

## Tecnologías

- TypeScript ~6.0.2
- Vite ^8.2.0

## Inicio rápido

### Prerrequisitos

- Node.js instalado

### Instalación

```bash
npm install
```

### Ejecución

```bash
npm run dev
```

### Compilación

```bash
npm run build
```

### Vista previa

```bash
npm run preview
```
